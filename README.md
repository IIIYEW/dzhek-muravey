# ДЖЕК МУРАВЕЙ

Сайт комиссионного магазина техники в Томске: главная, каталог, карточка товара, информация о магазине, обмен техники и контакты.

## Запуск

Нужны Node.js >=22.12.0 и npm. Команды выполняются из корня проекта.

```sh
npm ci
npm run dev
```

Сайт: http://localhost:5173. API: http://localhost:4000. Vite проксирует запросы `/api` на backend.

Каталог пока отключён, поэтому ключи Avito для запуска не нужны. Серверные настройки описаны в `backend/.env.example`; при необходимости скопируйте его в `backend/.env`. Секреты не должны попадать в `VITE_` переменные: они доступны в браузере.

## Структура

- `frontend/src/app` — маршруты React Router и точка входа приложения.
- `frontend/src/pages` — страницы сайта.
- `frontend/src/components` — общие компоненты, каталог, галерея и секции магазина.
- `frontend/src/services/api` — запросы к REST API.
- `frontend/src/styles` — стили; порядок подключения задан в `main.tsx`.
- `frontend/public` — оригинальные фотографии, логотип, favicon и Montserrat с лицензией OFL.
- `backend/src` — Express, REST-маршруты, кеш и серверный клиент Avito.
- `shared` — общие типы и обработка списка товаров.
- `tests` — тесты API, кеша, фильтров и провайдера.
- `scripts/smoke.mjs`, `scripts/browser-smoke.mjs` — проверки запущенного сайта.

## Сборка и размещение

```sh
npm run build
npm start
npm run test:smoke -- http://127.0.0.1:4000
```

Express отдаёт `frontend/dist` и API с одного адреса. Порт задаётся через `PORT`, по умолчанию — 4000. Прямые ссылки на страницы обрабатываются SPA fallback; отсутствующие файлы возвращают 404.

Для временного показа подготовлен `render.yaml`. Порядок публикации и ограничения бесплатного тарифа: [DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Каталог и Avito

Источник отключён намеренно. `/api/health` возвращает 200, запросы каталога — 503 с `sourceAvailable: false`. Интерфейс показывает недоступность источника, а не пустой ассортимент. Фиктивных товаров нет. Добавление ключей не включает запросы автоматически.

Перед подключением нужно проверить права приложения и актуальный контракт Item API. OAuth и ключи остаются только на сервере. Оставшиеся задачи отмечены `#TODO(Avito)`.

## Индексация

Без `SITE_URL` сервер запрещает индексацию через `robots.txt`, а `/sitemap.xml` возвращает 503. Для основного домена задайте `SITE_URL` на сервере и `VITE_SITE_URL` перед сборкой frontend. Метаданные формируются в браузере; серверного рендеринга нет.
