# Демонстрация на GitHub Pages

Публикуется только frontend из существующего репозитория `IIIYEW/dzhek-muravey`, ветка `master`. Backend остаётся в проекте, но на Pages не запускается. Каталог сообщает, что Avito не подключён; запросов к API и фиктивных товаров нет.

## Включение

1. В GitHub откройте репозиторий → **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. В **Actions → GitHub Pages** дождитесь успешного выполнения. Если отправка коммита произошла до включения Pages, нажмите **Run workflow** для ветки `master`.
4. Адрес после успешной публикации: https://IIIYEW.github.io/dzhek-muravey/ . Реальную готовность подтверждает успешный deploy, а не наличие этого документа.

Никаких ключей и банковских карт для workflow не нужно: используется встроенный `GITHUB_TOKEN`. Репозиторий не переключается в публичный автоматически. Если текущий тариф не разрешает Pages для приватного репозитория, сначала отдельно решите вопрос доступа; не публикуйте исходники и секреты ради включения сайта без проверки.

## Сборка

```sh
npm ci
npm run build:pages
```

Результат — `frontend/dist`. Режим `pages` задаёт префикс `/dzhek-muravey/` и hash-маршрутизацию: `#/catalog`, `#/about`, `#/contacts`, `#/exchange`, `#/catalog/123`. Обновление такой ссылки не требует серверного SPA fallback. Обычные `npm run build` и `npm start` сохраняют прежнюю работу с Express и чистыми URL.

После каждого push в `master` workflow проверяет код и публикует только frontend/dist. Файлы окружения и backend в артефакт не входят. Чтобы остановить обновления, отключите workflow в Actions.

## Проверка

Откройте главную и все разделы, обновите прямую ссылку `#/about`, проверьте фотографии, логотип, шрифты и мобильное меню. Каталог и карточка `#/catalog/123` должны сообщать о недоступности источника без ошибок запроса `/api`.

Демонстрация помечена `noindex`, но это не защита доступа. Любой обладатель ссылки может её открыть. Pages используется для временного просмотра интерфейса, не для эксплуатации интернет-магазина; перед постоянным размещением учитывайте ограничения GitHub Pages для коммерции: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits . Доступность из конкретной сети России нужно проверить у получателя.
