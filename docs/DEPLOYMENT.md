# Временный показ на Render Free

## Что подготовлено

В корне есть `render.yaml`: один бесплатный Node.js Web Service собирает frontend и backend, затем Express отдаёт сайт и API с одного HTTPS-адреса. Дизайн и работа каталога не меняются. Это конфигурация, а не подтверждение опубликованного сайта.

## Публикация

1. Убедитесь, что актуальные изменения сайта и `render.yaml` загружены в репозиторий `https://github.com/IIIYEW/dzhek-muravey`. Локальные незакоммиченные изменения Render не увидит. Не загружайте `.env.local`, `backend/.env`, токены и ключи.
2. Откройте https://dashboard.render.com/ и войдите в свой аккаунт. При необходимости подключите GitHub, предоставив доступ только к этому репозиторию.
3. Выберите **New → Blueprint**, затем репозиторий `dzhek-muravey` и ветку с актуальным кодом. Render должен обнаружить `render.yaml` в корне.
4. Перед подтверждением проверьте: один Web Service, тариф **Free**, без баз данных, дисков и платных дополнений. Если интерфейс предлагает только платный тариф, не подтверждайте создание.
5. Подтвердите создание и дождитесь завершения сборки и статуса **Live**. Адрес появится в карточке сервиса: `https://<имя-сервиса>.onrender.com`. Точное имя назначает Render; заранее готовой ссылки нет.

Если Blueprint недоступен, создайте **New → Web Service** вручную:

| Настройка         | Значение                                |
| ----------------- | --------------------------------------- |
| Runtime           | Node                                    |
| Root Directory    | Оставить пустым (корень репозитория)    |
| Build Command     | `npm ci --include=dev && npm run build` |
| Start Command     | `npm start`                             |
| Instance Type     | Free                                    |
| Health Check Path | `/api/health`                           |
| NODE_VERSION      | `24.15.0`                               |
| NODE_ENV          | `production`                            |

`PORT` задаёт Render. `SITE_URL`, `VITE_SITE_URL` и credentials Avito для временного показа не задавайте. Секреты нельзя помещать в `VITE_` переменные. Автоматическая публикация из Blueprint отключена; дальнейшее обновление запускайте через **Manual Deploy → Deploy latest commit** после загрузки изменений в GitHub.

## Проверка опубликованной копии

- Откройте главную, `/about`, `/contacts`, `/exchange`, `/catalog` напрямую и обновите страницу.
- Проверьте фото, шрифты, мобильное меню и ссылки для звонка.
- `/api/health` должен вернуть HTTP 200, `status: "ok"` и `catalog.sourceAvailable: false`.
- `/api/products` и `/api/products/123` должны вернуть HTTP 503: Avito намеренно не подключён. Интерфейс сообщает о недоступности каталога, а не показывает фиктивные товары.
- `/robots.txt` должен запрещать индексацию. Это рекомендация поисковикам, не защита доступа: любой обладатель ссылки сможет открыть сайт.
- `/sitemap.xml` без `SITE_URL` отвечает 503 — это ожидаемо для временной копии.

## Бесплатные ограничения

По официальной документации Render, проверенной при подготовке: после 15 минут без входящего трафика сервис засыпает; пробуждение занимает около минуты. Откройте сайт заранее перед показом. Бесплатные часы (750 в месяц на рабочее пространство), трафик и время сборки ограничены. Файловая система непостоянная; для этого сайта без загрузок и базы это не мешает показу.

Не подключайте платные ресурсы. Без платёжного метода превышение бесплатных лимитов приводит к приостановке сервисов или сборок; при добавленной карте возможна оплата перерасхода трафика/сборок — проверьте ограничения расходов в аккаунте. После показа ненужный сервис можно удалить в Render.

Условия могут меняться: https://render.com/docs/free и https://render.com/docs/blueprint-spec.

## Что пока не выполнено

Создание сервиса, внешняя сборка и проверка публичного адреса требуют авторизованного аккаунта Render. Локальная сборка не доказывает успешную публикацию. Не отправляйте пароли и токены в чат; для разбора ошибки достаточно обезличенного журнала сборки.
